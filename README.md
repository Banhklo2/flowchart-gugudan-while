# 🔢 FlowChart Gugudan While

**FlowChart로 단별 구구단 로직을 설계하고 Java로 구현한 연습**

---

## ✅ 시나리오: 구구단 출력 시스템

- 사용자가 **1 이상의 정수 숫자**를 입력한다.
- 사용자가 **입력한 단의 구구단을 출력한다.**
- 프로그램 종료 시 **해당 단의 구구단 출력이 완료되었음을 알린다.**

## 📌 입력 / 출력 정리

### 입력(Input)
- 사용자가 입력하는 정수 `num`

### 출력(Output)
- 해당 단의 구구단 (num x 1 ~ num x 9)

### 상태(State)
- `num` : 입력받은 정수
- `i` : 곱해지는 수

---

## 🔎 조건 정리

### 종료 조건
- i가 9보다 커지면 종료
  
### 분기 조건
- 입력값이 1 이상의 정수인가?

### 예외 / 에러 조건
- 숫자가 아닌 값이 입력된 경우  
  → `"정수를 입력하세요"` 출력 후 다시 입력받기  
- num < 1 인 경우  
  → `"1 이상 입력하세요"` 출력 후 다시 입력받기  

---

## 🔁 로직 흐름 설계

1. 시작 시 한 번만 실행
   - `i = 1` 으로 초기화한다.

2. 반복
   1) 정수 `num`을 입력받는다.  
   2) 입력값이 1 이상의 정수인지 확인한다.  
      - 예 → i = 1 초기화하고 반복 시작  
      - 아니오 → "1 이상의 정수를 입력하세요" 출력 후 다시 입력받기  
   3) num x i 값을 출력한다.
   4) i = i + 1 로 상태를 업데이트한다.  

3. 종료 시
- 해당 단의 구구단을 출력한다.
- 프로그램을 종료한다.
